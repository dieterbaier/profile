[cols="1,2,2", options="header"]
|===
| Building block | Responsibility | Storage
| Profile Content | CV, profile pages, articles, shorts, project history, and reusable fragments. | `src-content/profile`
| Architecture Knowledge | arc42 chapters, ADRs, quality scenarios, risks, canvases, Q&A, and metadata. | `src-content/docs`
| Validators | Check architecture and profile metadata. | `scripts/`
| Generators | Create derived indexes and traceability fragments. | `scripts/` and generated folders
| Gradle Tasks | Orchestrate build, validation, generation, conversion, and asset copying. | `build.gradle`
|===
