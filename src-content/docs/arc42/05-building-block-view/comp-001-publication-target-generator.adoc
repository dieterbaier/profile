[[comp-001-publication-target-generator]]
== COMP-001: Publication Target Generator

=== Responsibility

The Publication Target Generator is a build-time component that reads article sidecar metadata and creates target-specific AsciiDoc inputs for public, preview, and private site builds.

It owns:

* status-based article selection;
* generated article matrix/navigation fragments;
* publication-target source lists for Gradle/Asciidoctor;
* target-specific HTML metadata decisions such as canonical URL eligibility and `noindex` mode.
* verification inputs that prove `build/site` does not contain preview or private articles.

It does not own:

* article prose;
* reviewer authentication;
* private repository access control;
* deployment credentials.

=== Inputs And Outputs

[cols="1,3", options="header"]
|===
| Kind | Description
| Input | `*.profile.yaml` article metadata and corresponding `*.adoc` source files
| Input | publication target, for example `public`, `preview`, or `private`
| Output | metadata-derived article matrix for the target
| Output | source include/build list for the target
| Output | target attributes for canonical and robots metadata handling
|===

=== Target Rules

[cols="1,3,2", options="header"]
|===
| Target | Article eligibility | HTML metadata
| Public | `status: published` and `channels` includes `website` | canonical links allowed, search indexing allowed
| Preview | `status: preview` plus public context | no canonical links, `noindex`
| Private | private repository content plus preview and published context | no canonical links, `noindex`
|===

=== Implementation Guard

This component must not be implemented before xref:adr-008-private-to-public-article-lifecycle[ADR-008] and xref:adr-009-private-repository-integration[ADR-009] are reviewed. The current component description defines the target shape, not an accepted implementation contract.
