== DOC-06001: Private To Public Article Lifecycle Runtime

=== Status

In progress. The backlog epic is tracked as https://github.com/dieterbaier/profile/issues/26[GitHub issue #26]. The lifecycle is accepted in xref:adr-008-private-to-public-article-lifecycle[ADR-008]. Public canonical metadata can proceed independently; private repository integration and promotion automation remain proposed in xref:adr-009-private-repository-integration[ADR-009], and no first promotion check has yet been performed.

=== Scenario 1: Draft Private Article

include::../09-architecture-decisions/adr-008-private-to-public-article-lifecycle.adoc[tag=runtime-private-draft]

The private site is a reading and review surface for the author. It is not a substitute for source privacy; private content remains in the private repository.

=== Scenario 2: Promote Article To Preview

include::../09-architecture-decisions/adr-008-private-to-public-article-lifecycle.adoc[tag=runtime-promote-preview]

After promotion, preview content is public-source content. It is not official publication content, but it must no longer contain information that depends on private repository confidentiality.

=== Scenario 3: Publish Reviewed Article

include::../09-architecture-decisions/adr-008-private-to-public-article-lifecycle.adoc[tag=runtime-publish-reviewed]

Publishing is an explicit metadata transition. The public target must not include preview or private articles.

=== Scenario 4: Reject Or Continue Private Draft

include::../09-architecture-decisions/adr-008-private-to-public-article-lifecycle.adoc[tag=runtime-continue-private]

If an article is not ready to become public-source preview material, it stays private. No generated preview or public artifact is expected.
