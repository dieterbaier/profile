= Runtime View

== Build And Publish Scenario

[plantuml]
----
@startuml
start
:Detect changed paths;
:Validate architecture metadata;
:Validate profile metadata;
:Generate derived architecture fragments;
:Generate profile indexes;
:Render AsciiDoc outputs;
:Convert selected DocBook outputs to Markdown;
:Copy assets;
:Deploy affected artifacts;
stop
@enduml
----

== Failure Scenario

If metadata validation fails, Gradle stops before rendering or deployment. This keeps generated artifacts from drifting away from source truth.
