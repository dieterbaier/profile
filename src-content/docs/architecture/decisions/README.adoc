*Dieses Verzeichnis enthält alle **Architecture Decision Records (ADRs)** des `profile-dieterbaier`-Projekts.*

*ADRs folgen der **Vorlage von Mark Nygard** (https://adr.github.io/):

* Jede Entscheidung ist eine **eigenständige Datei**
* Jede Datei dokumentiert eine **signifikante Architekturentscheidung**
* ADRs sind **unveränderlich** (immutable) - neue Erkenntnisse führen zu neuen ADRs, nicht zu Änderungen

== ADR-Lebenszyklus

[.text-center]
[plantuml]
----
@startuml
left to right direction

[Proposed] --> [Accepted] : "Entscheidung getroffen"
[Accepted] --> [Deprecated] : "Bessere Alternative\ngefunden"
[Accepted] --> [Superseded] : "Ersetzt durch\nneuen ADR"
[Deprecated] --> [Rejected] : "Zurückgewiesen"

legend right
  |✅ Accepted | Aktiv und umgesetzt |
  |⚠️ Proposed | Vorschlag, noch nicht beschlossen |
  |❌ Deprecated | Veraltet, aber noch sichtbar |
  |❌ Superseded | Ersetzt durch neueren ADR |
  |❌ Rejected | Abgelehnt |
endlegend

@enduml
----

== ADR-Vorlage (Mark Nygard)

Jeder ADR folgt dieser Struktur:

```adoc
= ADR-XXX: Titel der Entscheidung

== Status
✅ Akzeptiert | ⚠️ Vorschlag | ❌ Veraltet | ❌ Ersetzt | ❌ Abgelehnt

== Kontext
// Hintergrund und Problemstellung

== Entscheidungsgrundlage
// Welche Optionen wurden in Betracht gezogen?

== Entscheidung
// Welche Option wurde gewählt?

== Konsequenzen
// Positive und negative Konsequenzen
// == Vorteile
// == Nachteile

== Alternativen
// Welche Alternativen wurden verworfen? Warum?

== Verknüpfungen
// Links zu anderen Dokumenten, die von dieser Entscheidung betroffen sind
```
