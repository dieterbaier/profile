Eine Einstellung dafür finde ich in der Dokumentation nicht.

Die Domain Ihres Internetanbieters kann erkennbar bleiben.

In meinen Logfiles vom Oktober 2026 habe ich auch einzelne Einträge mit nicht anonymisierter IP-Adresse gefunden. Das kläre ich mit STRATO.

Ich nutze diese Daten für den technischen Betrieb und die Sicherheit der Website und sehe die Logfiles gelegentlich selbst durch, etwa um die Anonymisierung zu prüfen. Zur Profilbildung nutze ich sie nicht.


=== Kommentarfunktion (GitHub)

Artikel auf dieser Website haben eine Kommentarfunktion, die auf GitHub aufbaut (GitHub, Inc., USA, und GitHub B.V., Prins Bernhardplein 200, 1097JB Amsterdam, Niederlande). Solange Sie sie nicht nutzen, baut eine Artikelseite keine Verbindung zu GitHub auf.

*Kommentare laden:* Erst wenn Sie die Schaltfläche dafür anklicken, ruft Ihr Browser direkt die Schnittstelle `api.github.com` auf. GitHub erhält dabei Ihre IP-Adresse, die üblichen Verbindungsdaten und die Kennung des Artikels. Eine Anmeldung bei GitHub wird dabei nicht mitgeschickt. Solche Anfragen ordnet GitHub https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api[nach eigener Angabe^] der IP-Adresse zu.

*Kommentar schreiben:* Der Link öffnet in einem neuen Tab ein Formular auf github.com, in dem Kennung, Titel und Adresse des Artikels vorausgefüllt sind. Zum Absenden brauchen Sie ein GitHub-Konto. Ihr Kommentar wird als öffentliches Issue im Repository `dieterbaier/profile-artikelkommentare` gespeichert und ist mit Ihrem GitHub-Benutzernamen für alle sichtbar. Ich kann ihn dort lesen, beantworten und moderieren.

*Was GitHub erfasst:* Nach https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement[eigener Datenschutzerklärung^] erfasst GitHub automatisch unter anderem IP-Adresse, Geräteinformationen und Sitzungsdaten sowie die verweisende Seite und den Zeitpunkt des Besuchs. Eine konkrete Speicherfrist für diese Daten nennt GitHub nicht; sie hänge vom Zweck der Erhebung und von gesetzlichen Pflichten ab. GitHub verarbeitet Daten auch in den USA und stützt sich dafür nach eigener Angabe auf die EU-Standardvertragsklauseln und das EU-U.S. Data Privacy Framework. Auf github.com setzt GitHub https://docs.github.com/en/site-policy/privacy-policies/github-cookies[eigene Cookies^]. Auf all das habe ich keinen Einfluss.
